# Трасса для Android - AR-карта труб и кабелей в стенах

> Стены помнят. Вы - спокойны.

Android-версия приложения [«Трасса» для iPhone](https://github.com/alenchha/trassa-ar). На черновом этапе ремонта вы отмечаете в AR, где на стене идут трубы и кабели. Через месяцы, уже после отделки, приложение показывает их на тех же местах и подсказывает, где сверлить нельзя.

## Проблема

После чистовой отделки никто не помнит, где проходят трассы, и при сверлении под мебель их повреждают. Фото штроб в галерее не помогают: их нельзя точно наложить на готовую стену. Подробнее о проблеме и результатах CustDev-интервью с прорабами - в [README iOS-версии](https://github.com/alenchha/trassa-ar#проблема).

## Чем отличается от iPhone-версии

На iPhone комната узнаётся автоматически: ARKit сохраняет карту комнаты (`ARWorldMap`) в файл. **В ARCore такой функции нет.** Есть Google Cloud Anchors, но им нужен интернет и сервер Google, а приложение должно работать офлайн и без регистрации.

Поэтому здесь комната узнаётся **по ориентирам (реперным точкам)**:

1. **При записи** после трасс вы отмечаете прицелом **3 ориентира** - то, что не изменится после ремонта: угол стены, край дверного или оконного проёма, угол у потолка. Для каждого сохраняются координаты и фото.
2. **При просмотре** приложение по очереди показывает фото ориентиров, и вы ставите прицел на те же места.
3. **Совмещение.** В каждой AR-сессии ARCore направляет ось Y против гравитации, поэтому две сессии отличаются только поворотом вокруг вертикали и сдвигом. Приложение находит их методом наименьших квадратов ([`Alignment.kt`](app/src/main/java/ru/trassa/geometry/Alignment.kt)) и переносит трассы на стену.
4. Приложение показывает **погрешность совмещения**. Если она больше 5 см, оно просит отметить ориентиры заново.

## Стек

- Kotlin, Jetpack Compose, Android 7.0+ (minSdk 24 - минимум для ARCore), targetSdk 37
- ARCore 1.56 + SceneView 4.66 (Filament) для отрисовки линий и зон
- Room: объекты, комнаты, трассы, точки, ориентиры, заметки; фото - файлами
- `PdfDocument` для экспорта, `Vibrator` для вибрации
- JUnit + Robolectric для тестов

## Как установить на телефон

Нужен Android-телефон с **поддержкой ARCore**: [список устройств](https://developers.google.com/ar/devices). Если «Сервисы Google Play для AR» не установлены, приложение предложит поставить их из Google Play.

### Вариант 1. Готовый APK (без компьютера)

1. Скачайте `trassa.apk` со страницы [Releases](../../releases) (или получите файл в мессенджере).
2. Откройте файл на телефоне. Если Android спросит, разрешите установку из этого источника: **Настройки → Установка неизвестных приложений**.
3. Нажмите **Установить**, затем откройте «Трассу» и разрешите доступ к камере.

### Вариант 2. Из Android Studio

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. На телефоне включите **режим разработчика** (Настройки → О телефоне → 7 раз нажмите «Номер сборки») и **Отладку по USB** (Настройки → Для разработчиков).
3. Подключите телефон кабелем, разрешите отладку, выберите его в списке устройств и нажмите **▶ Run**.

Собрать APK из командной строки:

```bash
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest # тесты
```

> AR в эмуляторе Android работает только в виртуальной сцене, для проверки на настоящей стене нужен телефон.

## Как проверить

1. Создайте объект → «Создать и записать комнату».
2. Поводите телефоном по стене, пока индикатор не покажет 3–4 столбика. Поставьте несколько точек, нажмите «Закончить линию». Повторите с другим типом трассы.
3. Нажмите «Сохранить» и отметьте 3 ориентира: например, два угла окна и угол комнаты.
4. Закройте приложение, отойдите в другое место и откройте комнату → «Открыть в AR». Отметьте ориентиры по фото. Трассы появятся на своих местах, вверху будет показана погрешность.
5. «Можно ли тут сверлить?»: ближе 15 см к линии плашка красная и телефон вибрирует, дальше - зелёная. Сверьте расстояние с рулеткой.

## Ограничения MVP

- **Точность зависит от того, как точно отмечены ориентиры.** Ошибка в 1 см на ориентире даёт около 1 см на трассе, но далеко от ориентиров ошибка поворота растёт. Выбирайте ориентиры по разным краям стены.
- Ориентиры нужно отмечать **в том же порядке**, что при записи. Приложение помогает фотографиями.
- Плоская схема в PDF - развёртка всех трасс на одну плоскость. Для нескольких стен она приблизительная.
- Результат - подсказка, а не гарантия: **перед сверлением проверяйте детектором проводки**.
- Нет синхронизации: данные хранятся на одном телефоне.

## Планы

- Автоматическое уточнение совмещения по найденным плоскостям стен.
- Совместимость данных с iOS-версией (экспорт и импорт комнаты).
- Опционально - Google Cloud Anchors для автоматического узнавания комнаты (с интернетом).
